# 云原生可观测性平台 — 总体设计文档（v4 SaaS 对齐版）

## 1. 定位

`ops-system` 是 **Datadog 式 SaaS 可观测控制面**（对齐 TCOP / UModel 演进方向），统一管理：

- **监控（Phase 1）**：VictoriaMetrics 共享 VMCluster 池 + vmauth 多工作空间 + VMAgent 采集
- **日志（Phase 1 数据面）**：Vector Agent → Kafka → Vector Aggregator → VictoriaLogs；logstore 抽象预留 ClickHouse/Doris
- **告警（Phase 1）**：平台自管规则/事件/渠道；评估走 VMRule；事件经 Alertmanager Webhook 回流
- **链路（后续）**：Tempo / OTel（控制台已留「链路追踪」入口占位）
- **UModel 骨架**：Entity / MetricSet / LogSet / DataLink

## 2. SaaS 多工作空间模型

```
Platform
 └── Zone（可用区监控面）
      └── Shared VMCluster 池（Helm k8s-stack + vmauth）
           └── Workspace → VMUser + ops_vm_routes
                └── 监控实例（Instance，shared）
                     └── BusinessCluster → VMAgent（collect-config）→ remoteWrite
```

**日志管道（Zone 级共享）**：

```
BusinessCluster → Vector Agent（U-001 标签 + logs_collect_config）
  → Kafka topic ops-logs-{zone}
  → Vector Aggregator → vlinsert → vlstorage → vlselect
  → ops-system logstore（LogsQL，强制工作空间标签过滤）
```

**唯一形态**：工作空间只拿 VMUser + 路由配额；独享（dedicated）模式已从产品路径移除。

### 2.1 控制台信息架构

嵌套域：概览 · 接入中心 · **监控**（监控实例 / 指标库 / Grafana）· **日志**（查询 / 日志实例）· 链路 · **告警**（事件 / 规则 / 静默）· **资源**（业务集群 / UModel）· **管理**（工作空间 / 用户 / 可用区 / 审计 / 设置）。

TopBar：**WorkspaceSwitcher**（平台 admin 可看全部）。

## 3. UModel 骨架（Phase 1）

| 概念 | 表 | 说明 |
|---|---|---|
| Storage | `ops_vm_clusters` | Zone 共享指标池 |
| LogStorage | `ops_log_clusters` | Zone 共享日志管道 |
| Entity | `ops_entities` | service / k8s_cluster / workload 等 |
| MetricSet | `ops_metric_sets` | 指标集元数据 |
| LogSet | `ops_log_sets` | 日志集元数据 |
| DataLink | `ops_data_links` | Entity ↔ MetricSet / LogSet |

**强制标签（U-001）**：`ops_tenant_id`（残余名 = Workspace UUID）, `ops_zone`, `ops_workspace`, `ops_cluster`

## 4. 告警与采集配置（摘要）

- **告警 API**：`/alerts/rules[/import]`、`/events`、`/channels`、`/stats/*`、`/webhooks/alertmanager`
- **静默**：UI 占位，规划 Alertmanager Silence
- **业务集群**：`GET/PUT .../collect-config`；指标（VMAgent）与日志（Vector）命名空间/间隔/路径过滤
