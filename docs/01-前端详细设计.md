# 前端详细设计（现网对齐版）

## 1. 技术栈

- React 19 + TypeScript
- MUI 7（Material Design 3）
- React Router v6
- Zustand（`useAuthStore` / `useWorkspaceStore`）
- axios + 自封装拦截器
- notistack（toast）
- recharts（概览统计）
- Vite

## 3. 路由与侧边栏

路由 path ↔ key 在 `appRouteMeta`；**侧栏结构**在 `sidebarNav`（可折叠分组）。

### 3.1 嵌套导航树

| 域 | 子入口 | 备注 |
|---|---|---|
| 概览 | `/dashboard` | |
| 接入中心 | `/integrations` | 顶层入口 |
| 监控 | 监控实例 · 指标库 · Grafana | `activePrefixes`: `/instances` `/metrics` `/grafana-instances` |
| 日志 | 日志查询 · 日志实例 | |
| 链路追踪 | `/traces` | 占位 |
| 告警 | 事件 · 规则 · 静默 | `activePrefixes`: `/alerts`；通知渠道为规则页内链 `/alerts/channels` |
| 资源 | 业务集群 · UModel | |
| 管理 | 工作空间 · 用户* · 可用区 · 审计* · 系统设置 | `*` = `requireAdmin` |

文案统一使用 **监控实例 / 日志实例 / 工作空间**，不再使用「指标空间 / 日志空间 / 租户 / 部门」。

### 3.2 子页面（不在侧栏叶子）

- `/alerts` → 重定向到规则页
- `/alerts/channels`：通知渠道（从规则页进入）
- `/clusters`、`/stats`：保留路由，由管理/概览内链进入
- 实例/Grafana 详情：`/instances/:id`、`/grafana-instances/:id`

### 3.3 requireAdmin

侧栏仅对平台 `user.role === 'admin'` 隐藏「用户」「审计」入口；路由仍可被书签访问，后端负责鉴权。

## 4. 鉴权与工作空间上下文

### 4.1 useAuthStore

- 持久化：`token` / `user`
- 登录：`POST /auth/login`；错误经 `extractLoginError` / `extractApiError`
- 全局 401：清 token + `UNAUTHORIZED_EVENT` → AuthGuard 跳登录

### 4.2 useWorkspaceStore + WorkspaceSwitcher

- TopBar 工作空间切换：平台 admin 可选「全部工作空间」
- 列表页通过 `WorkspaceFilterSelect` / store 注入 `workspace_id` 查询参数
- 成员角色判断见 `utils/membership.ts`（`admin` / `member` / `viewer`）

### 4.3 路由守卫

- `AuthGuard`：未登录 → `/login`
- `GuestGuard`：已登录访问 `/login` → `/dashboard`

## 5. 错误处理（extractApiError）

定义于 `api/index.ts`，页面 `catch` 统一使用：

```ts
catch (err) {
  enqueueSnackbar(extractApiError(err, '操作失败'), { variant: 'error' });
}
```

提取顺序：`data.message` / `data.error` → 状态码中文映射 → 网络错误 → fallback。

## 6. 请求取消（AbortController）

`api/client.ts`：`makeAbortController` / `isAbortError` / `withSignal`。
接入中心、实例详情等并发列表在 cleanup 中 abort，防止旧响应覆盖。

## 7. 关键页面

### 7.1 Dashboard
概览：接入/实例状态 + 告警统计图表（调用 `/alerts/stats/*`），避免假数据。

### 7.2 Workspace（工作空间）
CRUD + 成员管理（`admin` / `member` / `viewer`）。替代原 Tenant / Department。

### 7.3 监控 · Instance / InstanceDetail

| Tab | 内容 |
|---|---|
| 基本信息 | 元数据 / 配额 / 状态 |
| 数据采集 | 接入安装列表，跳转接入中心 `?instanceId=` |
| Dashboard | 已下发 Grafana dashboard |
| 告警 | 已下发 VMRule（只读）+ 跳转平台告警规则/事件 |

### 7.4 接入中心 / 指标库
模板分类树、版本管理、安装向导（dry-run → 安装）、指标库 DataGrid 与关联抽屉。

### 7.5 日志 · LogQuery / LogInstance
LogsQL 查询台；日志实例 CRUD。

### 7.6 告警域（`pages/Alert/*`）

| 页 | 路径 | 能力 |
|---|---|---|
| 事件 | `/alerts/events` | 列表、级别过滤、确认 ack、工作空间过滤 |
| 规则 | `/alerts/rules` | CRUD、Prometheus YAML/Zip **批量导入**、跳转渠道 |
| 渠道 | `/alerts/channels` | 通知渠道 CRUD |
| 静默 | `/alerts/silences` | 路线图占位（Alertmanager Silence） |

### 7.7 资源 · BusinessCluster
业务集群列表；**采集配置**对话框（指标：间隔/超时/命名空间；日志：命名空间/路径排除）；启停日志采集。

### 7.8 资源 · UModel
Entity / MetricSet / **LogSet** / DataLink 管理。

### 7.9 Grafana / Zone / Cluster / Audit / Settings
- Grafana 实例列表与详情（SSO 登录、Dashboard Tab）
- Zone：preflight / components / init-shared|logs|grafana
- Cluster：K8s 注册表
- Audit：平台审计（admin）
- Settings：个人信息、共享栈初始化等

### 7.10 Trace
链路追踪占位页。

## 8. API 约定

- 统一 axios 实例；`Authorization: Bearer <token>`
- 列表过滤优先传 `workspace_id`（后端部分写入体仍可能出现残余字段名 `tenant_id`）
- 写操作幂等键由调用方生成（`crypto.randomUUID()`）

## 9. 设计规范

- UI 统一 MUI 主题；文案与后端能力边界对齐
- 告警为平台一等功能，不再引导「N9E 独立引擎」
- 不在前端缓存敏感字段；token 仅 store + localStorage
